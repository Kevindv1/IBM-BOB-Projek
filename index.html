Konfigurasi Google Gemini API Key

Cara mendapatkan API Key (gratis):

1. Buka aistudio.google.com/app/apikey

2. Login dengan akun Google Anda.

3. Klik "Create API Key" dan pilih project.

4. Salin seluruh API key (format AIza... atau AQ...) dan tempel di bawah.

⚠️ API key disimpan hanya di browser Anda (localStorage) dan tidak pernah dikirim ke server lain.
